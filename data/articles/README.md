# Статьи сайта

Одна статья — один файл `<slug>.json` в этой папке. Страница появляется по адресу
`/stati/<slug>/`, попадает в список `/stati/`, в sitemap.xml и получает разметку Article,
FAQPage и хлебные крошки. Внизу каждой статьи — квиз «Подбор за минуту».

Перед публикацией: `node scripts/check-articles.mjs` (без ошибок) и `npm run build`.

```json
{
  "slug": "kak-proveryayut-motocikl-v-koree",
  "title": "до 60 знаков, с запросом в начале",
  "description": "70–160 знаков: о чём статья и чем полезна",
  "h1": "Заголовок на странице",
  "lead": "1–2 предложения под заголовком",
  "date": "2026-10-26",
  "updated": "2026-11-02",
  "query": "запрос в Яндексе, под который написана статья (на странице не показывается)",
  "blocks": [
    { "h2": "Подзаголовок" },
    { "p": "Абзац. Можно **жирный** и [ссылку](/catalog/?type=moto) — внутреннюю (/…) или https://." },
    { "list": ["пункт", "пункт"] },
    { "ol": ["шаг 1", "шаг 2"] },
    { "note": "Выделенный блок: важное или вывод" }
  ],
  "faq": [{ "q": "Вопрос?", "a": "Ответ." }],
  "sources": [{ "title": "Название источника", "url": "https://…" }]
}
```

Правила:
- Факты о VELTOR — только те, что уже есть на сайте (`data/content.ts`, `lib/seo-pages.tsx`).
- Законы, пошлины, утильсбор, курсы — только со ссылкой на источник в `sources`.
- Итоговую цену не называть: цены меняются с курсом, расчёт — через квиз `/podbor/` или в Telegram.
- Внутренние ссылки — на каталог, страницы марок `/moto/<марка>/` и квиз `/podbor/`.
- Не повторять темы и тексты, которые уже есть на сайте.
